# AD. ユーザーリサーチ

## 概要

ユーザーリサーチは、実装する機能・デザイン・UXが実際のユーザーニーズに合致しているか検証するプロセスです。定性的な観察・インタビューを通じてペルソナを構築し、その結果を設計・企画に反映させることで、ビジネス価値を最大化します。

---

## 1. ジャーニーマップの構築

**ステージの定義：** ユーザーがプロダクトと関わる各段階を明確化
- **Awareness（認知）:** プロダクトを知る
- **Consideration（検討）:** 機能・価格を比較検討
- **Purchase/Decision（購買）:** 実際に利用開始
- **Retention（継続）:** 定期的に利用
- **Advocacy（推奨）:** 他のユーザーに推奨

**タッチポイント（接点）:** 各ステージで、ユーザーがプロダクトと関わる具体的な接触点
- Webサイト訪問 → 検索結果クリック → ホームページ → 詳細ページ閲覧 → 購入ボタンクリック

**ギャップの特定：** ユーザーの期待値と現実のズレを発見
- 「このステージではスムーズだが、次のステージで手間がかかっている」

**感情曲線の分析：** 各タッチポイントでのユーザー満足度を可視化

```
満足度 ↑
      │     ╱╲       ╱╲
      │    ╱  ╲     ╱  ╲
      │   ╱    ╲___╱    ╲
      └─────────────────→ 時間
        (購買直後は高い → 使いにくい → 満足に戻る)
```

---

## 2. ペルソナの構築

**ペルソナの構成要素：**
- 名前、年齢、職業、年収
- 週単位での行動パターン
- 目標・課題・ニーズ
- テクノロジーリテラシー
- プロダクト購買時の判断基準

**プロトペルソナ：** インタビュー前の仮説的ペルソナ
- ビジネスチーム・営業チームの経験則から構築
- 後続のリサーチで検証・修正

**ペルソナシートの作成：**
```
名前: 田中太郎（35歳、営業部長）
現在の課題: 営業資料作成に毎日3時間 → 成約率向上に時間が割けない
プロダクトに期待: テンプレート機能で資料作成時間を50%削減
購買の判断基準: コスト < 時間効率化の価値
```

**感情移入マップ:** ペルソナの言葉・考え・行動を一覧化し、チーム内で認識を統一

---

## 3. インタビュー・観察の実施

定性的なリサーチを通じて、ペルソナを検証・深掘りします。

- **In-depth Interview:** 1時間程度、対面またはZoomで実施
- **Contextual Inquiry:** 実務環境（例：営業現場）でユーザー行動を観察
- **5-7名程度のサンプル:** 質的飽和に達する水準
- **録音・書き起こし:** 後続分析のため、発言を記録

**リサーチから得られる知見：** ペルソナが実際に解決したい課題、プロダクト利用時の困難、期待値

---

## 4. インサイトの抽出・共有

リサーチ結果を分析して、設計・企画に活かす具体的なインサイトを抽出します。

- **共通パターンの発見:** 複数ユーザーから同じ課題が出ると「本質的ニーズ」の可能性が高い
- **チームとの共有:** ペルソナシート・感情移入マップ・動画クリップでビジュアル化し、開発チーム全体で「ユーザー像」を共有
- **設計への反映:** 「この機能は、ペルソナの○○という課題を解決するため」と明確化
