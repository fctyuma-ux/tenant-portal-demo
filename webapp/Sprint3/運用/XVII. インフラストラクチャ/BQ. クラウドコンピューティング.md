# BQ. クラウドコンピューティング

## 概要

クラウドコンピューティングはスケーラビリティ・可用性・コスト効率の3つの利点を提供します。本セクションではクラウド環境でのコスト分析、最適化、ガバナンスをカバーします。

適切なコスト管理なしにクラウドを使用すると、予期しない費用増加につながります。

---

## 1. クラウド環境の特性

**スケーラビリティ**
- スケールアップ（垂直）：サーバーのスペックを上げる
- スケールアウト（水平）：サーバー数を増やす
- オートスケーリング：負荷に応じて自動調整

**可用性**
- 複数のデータセンターでの冗長化
- サービスレベルアグリーメント（SLA）：99.95% ～ 99.99%
- 自動フェイルオーバー機能

**従量課金モデル**
- 使った分だけ課金：予測可能なコスト
- リザーブドインスタンス：長期契約割引
- スポットインスタンス：余剰キャパシティの安価購入

---

## 2. コスト分析ツール

**AWS Cost Explorer の使用**
```
費用サマリー（過去 3ヶ月）：
├─ EC2：$3,500 / 月
├─ RDS：$2,100 / 月
├─ S3：$800 / 月
├─ Lambda：$200 / 月
└─ その他：$400 / 月

合計：$7,000 / 月
```

**ツールの機能**
- **日次・月次集計**：費用トレンドの把握
- **サービス別分析**：どのサービスに費用が集中しているか
- **予測**：今年度の見積もり
- **タグベース分析**：プロジェクト・部門ごとのコスト割り当て

## 3. コスト最適化戦略

**リソース効率化**
```
施策                      削減率    実装難易度
─────────────────────────────────────────
未使用インスタンス削除    20-30%    低
リザーブドインスタンス    30-40%    中
オートスケーリング        15-25%    中
ストレージ最適化           10-20%    低
ネットワーク最適化         5-10%    中
```

**実装例：リザーブドインスタンス**
```
オンデマンド：
  t2.medium × 24時間 × 30日 = 0.048 * 720 = $34.56 / 月

リザーブド（1年）：
  割引率 40% → $20.74 / 月

年間削減：(34.56 - 20.74) * 12 = $165.84
```

## 4. 費用の可視化と報告

**チームへのコスト共有**
```python
import boto3

ce_client = boto3.client('ce')

# コスト分析
response = ce_client.get_cost_and_usage(
    TimePeriod={
        'Start': '2024-01-01',
        'End': '2024-02-01'
    },
    Granularity='DAILY',
    Metrics=['UnblendedCost'],
    GroupBy=[
        {'Type': 'DIMENSION', 'Key': 'SERVICE'}
    ]
)

for item in response['ResultsByTime']:
    print(f"{item['TimePeriod']['Start']}: {item['Total']}")
```

**レポート共有**
- 月次コストレビュー会議
- サービス所有者への通知
- 異常値の自動アラート

## 5. ガバナンス・ポリシー

**クラウド使用ルール**
```
1. すべてのリソースにタグを付与（プロジェクト、コスト削減）
2. 未使用インスタンスは 7 日後に自動削除
3. 本番環境外での高価インスタンスは月 1 回レビュー
4. 新規サービス採用は事前に コスト試算が必須
5. 月次コスト超過時は管理者に報告
```

**ベストプラクティス**
- 開発・テスト環境の自動シャットダウン（営業時間外）
- ホワイトリスト型のインスタンスタイプ制限
- クラウド経費レビューの専任メンバー配置

## 6. 複数クラウド戦略

**クラウドの比較**
```
             AWS      GCP      Azure
─────────────────────────────────────
価格         中       低       中
マシン学習   弱       強       中
エンタープライズ 強  中       強
開発経験値   高       中       中
```

**マルチクラウド戦略**
- 単一ベンダー依存を回避
- 各サービスに最適なクラウド選択
- 移行コストと運用複雑性のトレードオフを考慮

---

## 7. 継続的な最適化

**月次レビュープロセス**
```
1. AWS Compute Optimizer の推奨事項を確認
2. 前月比での費用変化を分析
3. 異常なリソース使用を調査
4. チーム全体での改善提案
5. 改善を実装・効果測定
```

クラウドコストはアーキテクチャ決定から始まります。初期設計時にコスト効率を念頭におくことが重要です。
