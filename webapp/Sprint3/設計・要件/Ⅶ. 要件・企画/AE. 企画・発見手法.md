# AE. 企画・発見手法

## 概要

企画・発見手法は、新規プロダクトやフィーチャーのアイデアを短期間で検証し、実装価値を判断するプロセスです。デザインスプリントとビジネスモデルキャンバスを組み合わせることで、迅速な意思決定を実現します。

---

## 1. デザインスプリント（5日間のフェーズ）

デザインスプリントは、月曜日から金曜日の5日間で、アイデアから検証可能なプロトタイプまでを完成させます。

**フェーズの流れ:**
- **月曜（問題理解）:** チーム全員でチャレンジを共有し、ユーザーの視点を統一
- **火曜（提案立案）:** 既存ソリューションの研究と複数の提案案を作成
- **水曜（意思決定）:** チーム全員で提案を評価し、最も有望なものを選定
- **木曜（プロトタイプ作成）:** 選定案を細部まで詰めて、ユーザーテスト用プロトタイプを完成
- **金曜（ユーザーテスト）:** 実ユーザーに提案を検証し、フィードバックを収集

---

## 2. アイデア出出し手法

**HMW（How Might We）:**
- ユーザーの課題を「〇〇できるのではないか？」という問いに変換
- 例：「顧客獲得が困難」→「新規顧客の発見を効率化できるのではないか？」
- 視点を広げ、単なる改善ではなく、創造的なソリューションを導出

**クレイジー8:**
- 一人当たり8個のアイデアを8分で描写（1アイデアあたり1分）
- 質より量を重視し、批判なく、迅速にアイデアを外部化
- 異なる視点からの解決案を可視化

---

## 3. ビジネスモデルキャンバス

プロダクトの全体像を1枚で整理し、実現可能性を評価します。

```
┌──────────────────────────────────────────────────────────────┐
│ 主要パートナー  │  主要活動  │  価値提案  │  カスタマー   │
│      │         │            │            │ リレーション  │
├──────────────────────────────────────────────────────────────┤
│ 主要リソース    │            │            │  チャネル     │
├──────────────────────────────────────────────────────────────┤
│ コスト構造      │            │            │  収益源       │
│              │          顧客セグメント   │              │
└──────────────────────────────────────────────────────────────┘
```

**9つの要素:**
1. **顧客セグメント:** 誰にサービスを提供するか
2. **価値提案:** ユーザーにどんな価値を提供するか
3. **チャネル:** どのようにユーザーに届けるか
4. **カスタマーリレーションシップ:** 顧客との関係構築方法
5. **収益源:** どのように利益を得るか
6. **主要リソース:** 必要なリソース（人、技術、資金など）
7. **主要活動:** 実現に必要な活動
8. **主要パートナー:** 連携する外部パートナー
9. **コスト構造:** 運営に必要なコスト

ビジネスモデルキャンバスと従来の事業計画書の違いは、キャンバスが仮説を素早く検証するための簡潔なツールであること。定期的に見直し、ピボット（方向転換）を実施します。

---

## 4. ユーザーテストの実施

プロトタイプを実ユーザーに見せ、フィードバックを収集します。

**テストシナリオの作成:**
- 「登録から注文完了まで」など、ユーザーの主要な行動フローを定義
- 実行中に困ったポイント、改善案を記録
- テスト後、ユーザーの言葉でニーズを確認

テスト結果から改善優先度を判定し、繰り返しの実装検証を実施します。

---

## 5. イテレーションと方向転換

**ピボット（方向転換）:**
- 初期仮説が検証されなかった場合、戦略を大きく変更
- ユーザーセグメント、価値提案、ビジネスモデルなど、複数レベルでのピボットが考えられる
- 無駄な開発を避けるため、早期のピボット決定が重要

反復的なサイクルを通じて、最適なプロダクト・マーケット・フィット（PMF）を目指します。
