# AI. デザインシステム

## 概要

デザインシステムは、UI/UXの一貫性を保ちながら、デザインと実装の効率を高めるための包括的なツール・ガイド体系です。トークン（デザイン変数）を中心に、Single Source of Truthの原則で管理します。

---

## 1. トークンの階層構造

デザイン変数（トークン）を体系的に定義し、継承関係を明確にします。

**階層の例:**
```
Global / Base
  ├─ Color: primary-blue: #0066FF
  ├─ Spacing: base-unit: 8px
  └─ Typography: font-family: Arial

Component / Semantic
  ├─ button-primary-bg: var(--primary-blue)
  ├─ button-primary-padding: var(--base-unit) * 2
  └─ input-font: var(--font-family)

Alias / Variant
  ├─ success-color: var(--primary-green)
  └─ error-color: var(--primary-red)
```

グローバルトークン（基本色、基本スペーシング）を基に、コンポーネント層、エイリアス層と段階的に定義することで、保守性と柔軟性が向上します。

---

## 2. Single Source of Truth（SSOT）

すべてのデザイン決定が1つの場所で管理され、デザイナーと開発者が同じ定義を参照する仕組みです。

**実装方法:**
- **Figmaトークン機能:** デザインファイル内で変数を定義し、設計時から実装時まで使用
- **CSSカスタムプロパティ（CSS Variables）:** --color-primary: #0066FF などで実装側でも変数化
- **デザイントークンツール:** Tokens.studio、Supernova等で、デザインと実装の同期を自動化

定期的に同期状況を確認し、ズレが生じた場合は速やかに修正することが重要です。

---

## 3. テーマ切り替えの実装

ダークモード、ハイコントラストモードなど、複数のテーマに対応する設計です。

**実装パターン:**
```css
:root {
  --color-bg: #ffffff;
  --color-text: #333333;
}

@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #1a1a1a;
    --color-text: #f0f0f0;
  }
}
```

トークンの値をテーマごとに定義し、色やコントラストを調整。ユーザーの設定やOS設定に応じて自動切り替えできます。

---

## 4. ガイドの構成

デザインシステム利用者向けの包括的なドキュメント。

**必須項目:**
- **コンポーネントライブラリ:** ボタン、フォーム、カード等の使用例とバリエーション
- **Do's and Don'ts:** 正しい・間違った使用例を並べて説明
- **トークン一覧:** 色、スペーシング、タイポグラフィの定義と使用場面
- **ライティングガイド:** UI上のテキスト表現の統一ルール（トーン・オブ・ボイス）

---

## 5. ドキュメントサイトの公開

**公開プラットフォーム:**
- Figmaプラグイン：デザインファイルから自動生成
- Storybook：コンポーネントの対話的なカタログを作成
- 専用Webサイト：Zeroheight、Supernova等で、デザイン+実装コードを統一的に展開

定期的なアップデートと、利用者からのフィードバック収集により、デザインシステムを継続的に進化させます。

---

## 6. 導入と保守

**導入フェーズ:**
1. 既存デザインを分析し、パターンを抽出
2. トークンを定義し、実装コードと同期
3. チーム全体で運用ルールを決定
4. ドキュメントを公開し、利用を促進

**保守体制:**
- オーナーを決定し、トークン追加/変更リクエストを一元管理
- 定期的な監査で、デザインと実装のズレを検出
- 大規模な変更は段階的に導入し、影響を最小化
