# 要件定義書: ホーム画面（入居者）

## 目的

入居者がテナントポータルにログイン後、最初に表示される画面。AI質問（チャット）への導線と、よくある質問カテゴリを提示し、入居者が迷わず情報にアクセスできるようにする。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | AI質問入力 | 自然言語で質問を入力し、チャット画面へ遷移する | 新規 |
| 2 | よくある質問カテゴリ | ゴミ出し、空調、駐車場などの頻出カテゴリをカード形式で表示 | 新規 |
| 3 | お知らせ表示 | マニュアル更新やルール変更などの最新情報を表示 | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| AI質問入力 | 質問テキスト | テキストの受け取り、チャット画面への遷移パラメータ生成 | チャット画面へ遷移（質問テキストを引き継ぎ、即座にAI回答を開始） |
| よくある質問カテゴリ | カテゴリの選択（クリック） | 選択されたカテゴリに対応する質問テンプレートの生成 | チャット画面へ遷移（カテゴリに関連する質問で会話を開始） |
| お知らせ表示 | なし（画面表示時に自動取得） | お知らせデータの取得（最新順） | お知らせ一覧の表示（タイトル、日付、概要） |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| 質問入力バー | AI質問入力 | 空（プレースホルダー表示）→ 入力中 → 送信（チャット画面へ遷移） |
| カテゴリカード | よくある質問カテゴリ | 通常 → ホバー（ハイライト）→ クリック（チャット画面へ遷移） |
| お知らせセクション | お知らせ表示 | ローディング → 表示 → 空（お知らせなし時に「最新のお知らせはありません」表示） |
