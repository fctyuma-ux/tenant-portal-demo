# 要件定義書: チャット画面（AI回答）

## 目的

入居者がAIと対話形式でビル設備やルールについて質問し、回答を得る画面。ChatGPTのようなチャットUIを採用し、AI回答に加えてマニュアルの該当ページ画像や申請書PDFへのリンクを根拠として提示する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | AI対話 | ユーザーの自然言語質問に対し、AIがマニュアルの内容を元に回答する | 新規 |
| 2 | 根拠の引用表示 | AI回答の根拠となるマニュアルの該当ページ画像をサムネイルで提示する | 新規 |
| 3 | 関連ドキュメントリンク | 回答に関連する申請書PDFやマニュアルページへのダウンロードリンクを表示する | 新規 |
| 4 | 会話履歴 | 同一セッション内の質問・回答をスクロールで遡れる | 新規 |
| 5 | フィードバック | 回答が役に立ったかを「はい/いいえ」で評価する | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| AI対話 | ユーザーの質問テキスト | ナレッジベース（マニュアル+FAQ）を検索し、AIが回答を生成 | AI回答テキスト（吹き出し形式で表示） |
| 根拠の引用表示 | AI回答生成時に自動 | 回答の根拠となるマニュアルページを特定、サムネイル画像を取得 | マニュアル該当ページのサムネイル画像（クリックで拡大） |
| 関連ドキュメントリンク | AI回答生成時に自動 | 回答に関連する申請書PDF等のドキュメントを特定 | ダウンロードリンク（ファイル名+アイコン付き） |
| 会話履歴 | なし（自動蓄積） | 同一セッション内の質問・回答を保持 | スクロール可能な会話ログ |
| フィードバック | 「はい/いいえ」の選択 | 評価データをAPIに送信 | 送信完了の表示 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| メッセージ入力バー | AI対話 | 空（プレースホルダー表示）→ 入力中 → 送信中（無効化）→ 空（送信完了） |
| AI回答吹き出し | AI対話 | ローディング（タイピングアニメーション）→ テキスト表示 → テキスト+引用画像+リンク表示 |
| 引用画像サムネイル | 根拠の引用表示 | 非表示 → サムネイル表示 → 拡大モーダル表示（クリック時） |
| ドキュメントリンク | 関連ドキュメントリンク | 非表示 → リンク表示（該当ドキュメントがある場合のみ） |
| フィードバックボタン | フィードバック | 未評価（ボタン2つ表示）→ 送信中 → 評価済み（選択結果を表示、ボタン無効化） |
| チャットエリア | 会話履歴 | 空 → メッセージ追加（自動スクロール）→ スクロール可能 |
