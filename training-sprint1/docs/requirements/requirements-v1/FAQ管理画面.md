# 要件定義書: FAQ管理画面

## 目的

物件管理者がFAQを追加・編集・削除し、AIが回答できなかった質問への対応を強化する画面。入居者からのフィードバック（「役に立たなかった」）をもとに、ナレッジの改善を行う。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | FAQ一覧表示 | 登録済みFAQを一覧で表示（カテゴリ、質問、回答） | 新規 |
| 2 | FAQ追加 | 新規FAQの質問と回答を登録する | 新規 |
| 3 | FAQ編集 | 既存FAQの質問・回答を修正する | 新規 |
| 4 | FAQ削除 | 不要なFAQを削除する | 新規 |
| 5 | カテゴリ管理 | FAQのカテゴリ（ゴミ出し、空調、駐車場、申請手続き等）の管理 | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| FAQ一覧表示 | なし（画面表示時に自動取得）、カテゴリフィルタ、検索キーワード | FAQデータをDB検索、フィルタ・検索条件で絞り込み | FAQ一覧テーブル（カテゴリ、質問、回答プレビュー、作成日） |
| FAQ追加 | 質問テキスト、回答テキスト（リッチテキスト）、カテゴリ選択 | 入力データのバリデーション、DBへ新規レコード挿入 | 追加完了通知、一覧テーブルに新規行追加 |
| FAQ編集 | 修正後の質問テキスト、回答テキスト、カテゴリ | 入力データのバリデーション、DBレコード更新 | 更新完了通知、一覧テーブルの該当行が更新 |
| FAQ削除 | 削除ボタンクリック+確認 | DBレコード削除 | 一覧から該当行が消去 |
| カテゴリ管理 | カテゴリの選択 | 選択されたカテゴリでFAQを絞り込み | フィルタ済みFAQ一覧 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| FAQ一覧テーブル | FAQ一覧表示 | ローディング → データ表示 → 空（「FAQはまだ登録されていません」表示） |
| カテゴリフィルタ | カテゴリ管理 | 「すべて」選択（初期）→ カテゴリ選択 → テーブル絞り込み |
| 検索バー | FAQ一覧表示 | 空 → 入力中 → 検索実行（テーブル絞り込み） |
| FAQ追加ボタン | FAQ追加 | 通常 → クリック（モーダル表示） |
| FAQ編集モーダル | FAQ追加・FAQ編集 | 非表示 → 表示（空 or 既存データ入力済み）→ バリデーションエラー → 保存中 → 保存完了（モーダル閉じる） |
| 編集ボタン | FAQ編集 | 通常 → クリック（モーダル表示、既存データ読み込み） |
| 削除ボタン | FAQ削除 | 有効 → 確認ダイアログ表示 → 削除実行中 → 行消去 |
