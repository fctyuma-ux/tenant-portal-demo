# 要件定義書: ログイン画面

## 目的

入居者（総務担当者・一般社員）と管理者（物件管理者）がシステムにログインするための認証画面。ロールに応じて適切な画面へ遷移させる。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | メールアドレス・パスワード認証 | メールアドレスとパスワードによるログイン | 新規 |
| 2 | ロール別リダイレクト | 入居者はホーム画面、管理者は管理者ダッシュボードへ遷移 | 新規 |
| 3 | エラー表示 | 認証失敗時にエラーメッセージを表示 | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| メールアドレス・パスワード認証 | メールアドレス、パスワード | 認証APIへリクエスト、資格情報の検証 | 認証成功（トークン発行）/ 認証失敗（エラーメッセージ） |
| ロール別リダイレクト | 認証トークン（ロール情報含む） | ロール判定（入居者 or 管理者） | 入居者→ホーム画面 / 管理者→管理者ダッシュボード |
| エラー表示 | 認証APIのエラーレスポンス | エラー種別の判定 | エラーメッセージの表示（「メールアドレスまたはパスワードが正しくありません」等） |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| ログインボタン | メールアドレス・パスワード認証 | 無効（未入力時）→ 有効（入力済み）→ ローディング（認証中）→ 有効（失敗時） |
| メールアドレス入力 | メールアドレス・パスワード認証 | 空 → 入力中 → 入力済み → エラー（形式不正時） |
| パスワード入力 | メールアドレス・パスワード認証 | 空 → 入力中 → 入力済み |
| エラーメッセージ | エラー表示 | 非表示 → 表示（認証失敗時）→ 非表示（再入力開始時） |
