# 要件定義書: 管理者ダッシュボード

## 目的

物件管理者がログイン後に表示されるトップ画面。ドキュメント管理やFAQ管理への導線と、問い合わせ状況の概要を提供する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | 問い合わせ概要 | 直近の問い合わせ件数やよく聞かれる質問のサマリーを表示 | 新規 |
| 2 | ドキュメント管理への導線 | ドキュメント管理画面への遷移リンク | 新規 |
| 3 | FAQ管理への導線 | FAQ管理画面への遷移リンク | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| 問い合わせ概要 | なし（画面表示時に自動取得） | 直近の質問ログを集計、頻出トピックをランキング | 質問件数サマリー、よく聞かれるトピックTOP5 |
| ドキュメント管理への導線 | ナビゲーションまたはボタンのクリック | 画面遷移 | ドキュメント管理画面を表示 |
| FAQ管理への導線 | ナビゲーションまたはボタンのクリック | 画面遷移 | FAQ管理画面を表示 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| サマリーカード | 問い合わせ概要 | ローディング → データ表示 → 空（データなし時に「まだ問い合わせはありません」表示） |
| フィードバックサマリー | 問い合わせ概要 | ローディング → リスト表示 → 空（ネガティブ評価なし時） |
| サイドナビゲーション | 各画面への導線 | 現在のページがアクティブ表示 |
| クイックアクションボタン | 各画面への導線 | 通常 → ホバー → クリック（遷移） |
