# 要件定義書: ドキュメント管理画面

## 目的

物件管理者がテナントマニュアルPDFをアップロードし、AIのナレッジベースとして登録・管理する画面。アップロード後に公開する前に、テストプレビュー機能で正しくAI回答が生成されるかを確認できる。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | PDFアップロード | マニュアルPDFをドラッグ＆ドロップまたはファイル選択でアップロード | 新規 |
| 2 | AI解析処理 | アップロードされたPDFをAIが解析し、ナレッジベースに取り込む | 新規 |
| 3 | ドキュメント一覧 | 登録済みドキュメントの一覧表示（ファイル名、登録日、ステータス） | 新規 |
| 4 | テストプレビュー | 公開前にテスト質問を入力し、AI回答が正しく生成されるかを確認する | 新規 |
| 5 | 公開・非公開切替 | ドキュメントの公開ステータスを切り替える | 新規 |
| 6 | ドキュメント削除 | 不要になったドキュメントを削除する | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| PDFアップロード | PDFファイル（ドラッグ＆ドロップまたはファイル選択） | ファイルをサーバーにアップロード、AI解析処理をキック | アップロード完了通知、解析プログレスバー表示 |
| AI解析処理 | アップロードされたPDF | PDFからテキスト・画像を抽出、ベクトル化してナレッジベースに格納 | 解析完了（ステータスが「未公開」に変化） |
| ドキュメント一覧 | なし（画面表示時に自動取得） | 登録済みドキュメントをDB検索 | ファイル名、登録日、ページ数、ステータスの一覧テーブル |
| テストプレビュー | テスト質問テキスト | 未公開ドキュメントを含むナレッジベースに対してAI回答を生成 | AI回答テキスト+引用画像のプレビュー表示 |
| 公開・非公開切替 | トグル操作 | ドキュメントの公開ステータスをDB更新 | ステータス変更完了（「未公開」↔「公開中」） |
| ドキュメント削除 | 削除ボタンクリック+確認 | ドキュメントとナレッジベースデータをDB削除 | 一覧から該当行が消去 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| アップロードエリア | PDFアップロード | 待機（ドロップゾーン表示）→ ドラッグオーバー（ハイライト）→ アップロード中（プログレス表示）→ 完了 |
| 解析プログレスバー | AI解析処理 | 非表示 → 解析中（進捗%表示）→ 完了 → エラー（解析失敗時） |
| ドキュメント一覧テーブル | ドキュメント一覧 | ローディング → データ表示 → 空（「ドキュメントはまだ登録されていません」表示） |
| 公開トグルスイッチ | 公開・非公開切替 | OFF（未公開）→ 確認ダイアログ → ON（公開中）/ OFF（キャンセル時） |
| 削除ボタン | ドキュメント削除 | 有効 → 確認ダイアログ表示 → 削除実行中 → 行消去 |
| テストプレビュー枠 | テストプレビュー | 空（「テスト質問を入力してください」表示）→ 質問入力中 → AI回答生成中（ローディング）→ 回答+引用表示 |
