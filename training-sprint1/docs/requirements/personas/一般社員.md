# ペルソナ: 一般社員（佐藤 健太）

## ユーザー属性

| 項目 | 内容 |
|------|------|
| 名前 | 佐藤 健太 |
| 年齢 | 20代 |
| 職業 | 営業部 担当 |
| 部門 | 営業部 |
| 勤務地 | 大手町パークビルディング 12F |
| 技術スキル | 高（スマホネイティブ世代、チャットAIの利用経験あり） |

## 目標・ゴール

- ビルの設備やルールについて疑問が生じた時、自分ですぐに答えを見つけて本業に集中したい
- 総務担当者や管理事務所に聞くまでもない簡単な疑問を、手元のスマホで即座に解決したい
- 入居したばかりのビルのルールを早く覚えて、スムーズに業務環境に馴染みたい

## 課題

- マニュアルの存在は知っているが、PDFが長すぎて開く気にならない
- 「ゴミはどこに捨てるのか」「会議室の予約方法は」など、ちょっとした疑問のたびに総務に聞くのは気が引ける
- 防災設備の使い方や避難経路など、緊急時に必要な情報をすぐに確認できる手段がない

## 利用状況

| 利用場面 | 頻度 | 詳細 |
|---------|------|------|
| ビル設備の使い方に疑問を感じた時 | 週1〜2回 | ゴミの分別場所、喫煙所の場所、郵便物の受取方法などをスマホで検索する |
| 入居直後の環境把握 | 入居後1〜2週間集中 | ビルのルール全般を一通り確認する |
| 緊急時・トラブル発生時 | 不定期 | 停電時の対応、水漏れ時の連絡先、避難経路などを即座に確認する |
