# ペルソナ: 総務担当者（田中 美咲）

## ユーザー属性

| 項目 | 内容 |
|------|------|
| 名前 | 田中 美咲 |
| 年齢 | 30代 |
| 職業 | 総務部 主任 |
| 部門 | 総務部 |
| 勤務地 | 大手町パークビルディング 12F |
| 技術スキル | 中（業務でPC・スマホを日常的に使用、チャットツールやクラウドサービスに慣れている） |

## 目標・ゴール

- ビルの設備利用ルールや各種申請手続きを正確に把握し、社内からの問い合わせに即座に回答できるようになりたい
- 管理事務所への電話問い合わせの回数を減らし、総務業務全体の効率を上げたい
- 新入社員や異動者へのビル利用案内をスムーズに行いたい

## 課題

- マニュアルが画像・図面中心のPDFで、必要な情報を探すのに毎回10〜15分かかる
- ゴミの分別ルール、空調の操作方法、駐車場の利用手続きなど、社員から同じ質問を繰り返し受けるが、毎回マニュアルを確認し直している
- 入館証の発行手続きや工事申請など、申請フローが複雑で手順を忘れがち

## 利用状況

| 利用場面 | 頻度 | 詳細 |
|---------|------|------|
| 社員からビル設備に関する質問を受けた時 | 週3〜5回 | ゴミ出しルール、空調操作、共用部の利用方法などを調べて回答する |
| 各種申請手続きの確認 | 月2〜3回 | 入館証発行、工事申請、管球交換依頼などの手順を確認する |
| 新入社員・異動者へのビル案内準備 | 四半期に1回 | マニュアルから必要な情報を抜粋して案内資料を作成する |
