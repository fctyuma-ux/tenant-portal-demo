# 要件定義書 v2: チャット画面（AI回答）

> DB設計を踏まえた要件定義書の更新

## 目的

入居者がAIと対話形式でビル設備やルールについて質問し、回答を得る画面。ChatGPTのようなチャットUIを採用し、AI回答に加えてマニュアルの該当ページ画像や申請書PDFへのリンクを根拠として提示する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | AI対話 | ユーザーの自然言語質問に対し、AIがマニュアルの内容を元に回答する | DB関連テーブル: document_chunks, faqs, messages, conversations |
| 2 | 根拠の引用表示 | AI回答の根拠となるマニュアルの該当ページ画像をサムネイルで提示する | DB関連テーブル: document_chunks, documents |
| 3 | 関連ドキュメントリンク | 回答に関連する申請書PDFやマニュアルページへのダウンロードリンクを表示する | DB関連テーブル: documents |
| 4 | 会話履歴 | 同一セッション内の質問・回答をスクロールで遡れる | DB関連テーブル: conversations, messages |
| 5 | フィードバック | 回答が役に立ったかを「はい/いいえ」で評価する | DB関連テーブル: messages |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| AI対話 | ユーザーの質問テキスト | ナレッジベース（マニュアル+FAQ）検索、AI回答生成 | AI回答テキスト（吹き出し形式） | document_chunks (READ: embedding類似度検索), faqs (READ), messages (WRITE), conversations (WRITE) |
| 根拠の引用表示 | AI回答生成時に自動 | 根拠マニュアルページ特定、サムネイル取得 | マニュアル該当ページのサムネイル画像 | document_chunks (READ: page_number, page_image_path), documents (READ: file_name) |
| 関連ドキュメントリンク | AI回答生成時に自動 | 関連する申請書PDF等のドキュメント特定 | ダウンロードリンク（ファイル名+アイコン） | documents (READ: file_path, file_name) |
| 会話履歴 | なし（自動蓄積） | 同一セッション内の質問・回答を保持 | スクロール可能な会話ログ | conversations (READ), messages (READ) |
| フィードバック | 「はい/いいえ」の選択 | 評価データをAPIに送信 | 送信完了の表示 | messages (UPDATE: feedback) |

## UI状態遷移

| 要素 | 対応機能 | DB関連テーブル |
|------|---------|--------------|
| メッセージ入力バー | AI対話 | なし（フロントのみ） |
| AI回答吹き出し | AI対話 | document_chunks, faqs, messages |
| 引用画像サムネイル | 根拠の引用表示 | document_chunks (READ: page_image_path) |
| ドキュメントリンク | 関連ドキュメントリンク | documents (READ: file_path) |
| フィードバックボタン | フィードバック | messages (UPDATE: feedback) |
| チャットエリア | 会話履歴 | conversations, messages (READ) |
