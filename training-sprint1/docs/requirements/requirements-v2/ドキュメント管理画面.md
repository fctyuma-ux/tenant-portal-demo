# 要件定義書 v2: ドキュメント管理画面

> DB設計を踏まえた要件定義書の更新

## 目的

物件管理者がテナントマニュアルPDFをアップロードし、AIのナレッジベースとして登録・管理する画面。アップロード後に公開する前に、テストプレビュー機能で正しくAI回答が生成されるかを確認できる。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | PDFアップロード | マニュアルPDFをドラッグ＆ドロップまたはファイル選択でアップロード | DB関連テーブル: documents (WRITE) |
| 2 | AI解析処理 | アップロードされたPDFをAIが解析し、ナレッジベースに取り込む | DB関連テーブル: documents (UPDATE), document_chunks (WRITE) |
| 3 | ドキュメント一覧 | 登録済みドキュメントの一覧表示 | DB関連テーブル: documents (READ) |
| 4 | テストプレビュー | 公開前にテスト質問でAI回答が正しく生成されるか確認 | DB関連テーブル: document_chunks, faqs (READ) |
| 5 | 公開・非公開切替 | ドキュメントの公開ステータスを切り替える | DB関連テーブル: documents (UPDATE) |
| 6 | ドキュメント削除 | 不要になったドキュメントを削除する | DB関連テーブル: documents (DELETE), document_chunks (CASCADE DELETE) |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| PDFアップロード | PDFファイル（ドラッグ＆ドロップまたはファイル選択） | サーバーアップロード、AI解析処理キック | アップロード完了通知、プログレスバー表示 | documents (WRITE) |
| AI解析処理 | アップロードされたPDF | テキスト・画像抽出、ベクトル化、ナレッジベース格納 | 解析完了（ステータス「未公開」に変化） | documents (UPDATE: analysis_status), document_chunks (WRITE) |
| ドキュメント一覧 | なし（自動取得） | 登録済みドキュメントをDB検索 | 一覧テーブル（ファイル名、登録日、ページ数、ステータス） | documents (READ) |
| テストプレビュー | テスト質問テキスト | 未公開含むナレッジベースでAI回答生成 | AI回答+引用画像のプレビュー | document_chunks (READ: embedding類似度検索), faqs (READ) |
| 公開・非公開切替 | トグル操作 | 公開ステータスDB更新 | ステータス変更完了（未公開↔公開中） | documents (UPDATE: publish_status) |
| ドキュメント削除 | 削除クリック+確認 | ドキュメント+ナレッジベースデータ削除 | 一覧から該当行消去 | documents (DELETE), document_chunks (CASCADE DELETE) |

## UI状態遷移

| 要素 | 対応機能 | DB関連テーブル |
|------|---------|--------------|
| アップロードエリア | PDFアップロード | documents (WRITE) |
| 解析プログレスバー | AI解析処理 | documents (READ: analysis_status) |
| ドキュメント一覧テーブル | ドキュメント一覧 | documents (READ) |
| 公開トグルスイッチ | 公開・非公開切替 | documents (UPDATE: publish_status) |
| 削除ボタン | ドキュメント削除 | documents (DELETE) |
| テストプレビュー枠 | テストプレビュー | document_chunks, faqs (READ) |
