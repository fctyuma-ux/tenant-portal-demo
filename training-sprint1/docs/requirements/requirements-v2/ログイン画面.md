# 要件定義書 v2: ログイン画面

> DB設計を踏まえた要件定義書の更新

## 目的

入居者（総務担当者・一般社員）と管理者（物件管理者）がシステムにログインするための認証画面。ロールに応じて適切な画面へ遷移させる。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | メールアドレス・パスワード認証 | メールアドレスとパスワードによるログイン | DB関連テーブル: users (READ) |
| 2 | ロール別リダイレクト | 入居者はホーム画面、管理者は管理者ダッシュボードへ遷移 | DB関連テーブル: users (READ: role) |
| 3 | エラー表示 | 認証失敗時にエラーメッセージを表示 | DB関連テーブル: なし |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| メールアドレス・パスワード認証 | メールアドレス、パスワード | 認証APIへリクエスト、資格情報の検証 | 認証成功（トークン発行）/ 認証失敗（エラー） | users (READ) |
| ロール別リダイレクト | 認証トークン（ロール情報含む） | ロール判定（入居者 or 管理者） | 入居者→ホーム画面 / 管理者→ダッシュボード | users (READ: role) |
| エラー表示 | 認証APIのエラーレスポンス | エラー種別の判定 | エラーメッセージの表示 | なし |

## UI状態遷移

| 要素 | 対応機能 | DB関連テーブル |
|------|---------|--------------|
| ログインボタン | メールアドレス・パスワード認証 | なし（フロントのみ） |
| メールアドレス入力 | メールアドレス・パスワード認証 | なし（フロントのみ） |
| パスワード入力 | メールアドレス・パスワード認証 | なし（フロントのみ） |
| エラーメッセージ | エラー表示 | なし（フロントのみ） |
