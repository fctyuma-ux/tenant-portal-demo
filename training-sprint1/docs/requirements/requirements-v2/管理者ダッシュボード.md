# 要件定義書 v2: 管理者ダッシュボード

> DB設計を踏まえた要件定義書の更新

## 目的

物件管理者がログイン後に表示されるトップ画面。ドキュメント管理やFAQ管理への導線と、問い合わせ状況の概要を提供する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | 問い合わせ概要 | 直近の問い合わせ件数やよく聞かれる質問のサマリーを表示 | DB関連テーブル: messages, conversations |
| 2 | ドキュメント管理への導線 | ドキュメント管理画面への遷移リンク | DB関連テーブル: なし |
| 3 | FAQ管理への導線 | FAQ管理画面への遷移リンク | DB関連テーブル: なし |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| 問い合わせ概要 | なし（自動取得） | 質問ログ集計、頻出トピックランキング | 質問件数サマリー、トピックTOP5 | messages (READ: COUNT, GROUP BY), conversations (READ) |
| ドキュメント管理への導線 | クリック | 画面遷移 | ドキュメント管理画面を表示 | なし（フロントのみ） |
| FAQ管理への導線 | クリック | 画面遷移 | FAQ管理画面を表示 | なし（フロントのみ） |

## UI状態遷移

| 要素 | 対応機能 | DB関連テーブル |
|------|---------|--------------|
| サマリーカード | 問い合わせ概要 | messages, conversations (READ) |
| フィードバックサマリー | 問い合わせ概要 | messages (READ: feedback = 'negative') |
| サイドナビゲーション | 各画面への導線 | なし（フロントのみ） |
| クイックアクションボタン | 各画面への導線 | なし（フロントのみ） |
