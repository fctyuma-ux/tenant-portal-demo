# 要件定義書 v2: FAQ管理画面

> DB設計を踏まえた要件定義書の更新

## 目的

物件管理者がFAQを追加・編集・削除し、AIが回答できなかった質問への対応を強化する画面。入居者からのフィードバック（「役に立たなかった」）をもとに、ナレッジの改善を行う。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | FAQ一覧表示 | 登録済みFAQを一覧で表示（カテゴリ、質問、回答） | DB関連テーブル: faqs (READ) |
| 2 | FAQ追加 | 新規FAQの質問と回答を登録する | DB関連テーブル: faqs (WRITE) |
| 3 | FAQ編集 | 既存FAQの質問・回答を修正する | DB関連テーブル: faqs (UPDATE) |
| 4 | FAQ削除 | 不要なFAQを削除する | DB関連テーブル: faqs (DELETE) |
| 5 | カテゴリ管理 | FAQのカテゴリ（ゴミ出し、空調、駐車場、申請手続き等）の管理 | DB関連テーブル: faqs (READ) |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| FAQ一覧表示 | カテゴリフィルタ、検索キーワード | FAQデータDB検索、絞り込み | FAQ一覧テーブル（カテゴリ、質問、回答プレビュー、作成日） | faqs (READ) |
| FAQ追加 | 質問テキスト、回答テキスト、カテゴリ選択 | バリデーション、DBへ新規レコード挿入 | 追加完了通知、一覧テーブルに新規行追加 | faqs (WRITE) |
| FAQ編集 | 修正後の質問テキスト、回答テキスト、カテゴリ | バリデーション、DBレコード更新 | 更新完了通知、一覧テーブルの該当行が更新 | faqs (UPDATE) |
| FAQ削除 | 削除クリック+確認 | DBレコード削除 | 一覧から該当行消去 | faqs (DELETE) |
| カテゴリ管理 | カテゴリ選択 | 選択カテゴリでFAQ絞り込み | フィルタ済みFAQ一覧 | faqs (READ: DISTINCT category) |

## UI状態遷移

| 要素 | 対応機能 | DB関連テーブル |
|------|---------|--------------|
| FAQ一覧テーブル | FAQ一覧表示 | faqs (READ) |
| カテゴリフィルタ | カテゴリ管理 | faqs (READ: DISTINCT category) |
| 検索バー | FAQ一覧表示 | faqs (READ) |
| FAQ追加ボタン | FAQ追加 | なし（フロントのみ） |
| FAQ編集モーダル | FAQ追加・FAQ編集 | faqs (WRITE/UPDATE) |
| 編集ボタン | FAQ編集 | faqs (READ) |
| 削除ボタン | FAQ削除 | faqs (DELETE) |
