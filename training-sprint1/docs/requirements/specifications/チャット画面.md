# 仕様書: チャット画面（AI回答）

## 目的

入居者がAIと対話形式でビル設備やルールについて質問し、回答を得る画面。ChatGPTのようなチャットUIを採用し、AI回答に加えてマニュアルの該当ページ画像や申請書PDFへのリンクを根拠として提示する。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | AI対話 | ユーザーの自然言語質問に対し、AIがマニュアルの内容を元に回答する |
| 2 | 根拠の引用表示 | AI回答の根拠となるマニュアルの該当ページ画像をサムネイルで提示する |
| 3 | 関連ドキュメントリンク | 回答に関連する申請書PDFやマニュアルページへのダウンロードリンクを表示する |
| 4 | 会話履歴 | 同一セッション内の質問・回答をスクロールで遡れる |
| 5 | フィードバック | 回答が役に立ったかを「はい/いいえ」で評価する |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| ヘッダー | 物件名、戻るボタン | 上部 |
| チャットエリア | ユーザーの質問（右寄せ吹き出し）とAI回答（左寄せ吹き出し）の表示領域 | 中央（スクロール可能） |
| AI回答吹き出し | テキスト回答 + 引用画像サムネイル + 関連ドキュメントリンクを含む | チャットエリア内 |
| 引用画像サムネイル | マニュアルの該当ページ画像（クリックで拡大表示） | AI回答吹き出し内の下部 |
| ドキュメントリンク | 申請書PDFなどのダウンロードリンク（ファイルアイコン付き） | AI回答吹き出し内 |
| フィードバックボタン | 「役に立った / 役に立たなかった」ボタン | 各AI回答吹き出しの下 |
| メッセージ入力バー | テキスト入力欄と送信ボタン | 画面下部固定 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| AI対話 | メッセージ入力バー + チャットエリア | テキスト入力→送信でAI回答が吹き出しとして追加される |
| 根拠の引用表示 | 引用画像サムネイル | AI回答時に自動でマニュアル該当ページのサムネイルを表示。クリックで拡大モーダル |
| 関連ドキュメントリンク | ドキュメントリンク | AI回答内に申請書等のリンクが含まれる場合、アイコン付きリンクとして表示。クリックでダウンロード |
| 会話履歴 | チャットエリア | 上方向スクロールで過去の質問・回答を確認 |
| フィードバック | フィードバックボタン | ボタンクリックで評価を送信。UIが「送信済み」に変化 |
