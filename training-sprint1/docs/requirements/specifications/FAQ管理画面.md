# 仕様書: FAQ管理画面

## 目的

物件管理者がFAQを追加・編集・削除し、AIが回答できなかった質問への対応を強化する画面。入居者からのフィードバック（「役に立たなかった」）をもとに、ナレッジの改善を行う。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | FAQ一覧表示 | 登録済みFAQを一覧で表示（カテゴリ、質問、回答） |
| 2 | FAQ追加 | 新規FAQの質問と回答を登録する |
| 3 | FAQ編集 | 既存FAQの質問・回答を修正する |
| 4 | FAQ削除 | 不要なFAQを削除する |
| 5 | カテゴリ管理 | FAQのカテゴリ（ゴミ出し、空調、駐車場、申請手続き等）の管理 |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| ヘッダー・サイドナビ | 共通ナビゲーション | 上部・左側 |
| FAQ一覧テーブル | カテゴリ、質問、回答（プレビュー）、作成日を表示 | メインエリア中央 |
| カテゴリフィルタ | カテゴリで絞り込むドロップダウン | 一覧テーブル上部 |
| 検索バー | FAQ内をキーワード検索する | 一覧テーブル上部 |
| FAQ追加ボタン | 新規FAQ作成モーダルを開く | テーブル上部右 |
| FAQ編集モーダル | 質問入力、回答入力（リッチテキスト）、カテゴリ選択 | モーダル |
| 編集ボタン | 各FAQの編集モーダルを開く | 一覧テーブル内 |
| 削除ボタン | 各FAQの削除ボタン（確認ダイアログ付き） | 一覧テーブル内 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| FAQ一覧表示 | FAQ一覧テーブル + カテゴリフィルタ + 検索バー | 画面表示時にFAQを取得。フィルタ・検索で絞り込み |
| FAQ追加 | FAQ追加ボタン + FAQ編集モーダル | ボタンクリックでモーダル表示。質問・回答・カテゴリを入力し保存 |
| FAQ編集 | 編集ボタン + FAQ編集モーダル | 編集ボタンクリックで既存データをモーダルに表示。修正後に保存 |
| FAQ削除 | 削除ボタン | クリックで確認ダイアログ表示後、削除実行 |
| カテゴリ管理 | カテゴリフィルタ + FAQ編集モーダル内カテゴリ選択 | FAQ追加・編集時にカテゴリを選択 |
