# 仕様書: 管理者ダッシュボード

## 目的

物件管理者がログイン後に表示されるトップ画面。ドキュメント管理やFAQ管理への導線と、問い合わせ状況の概要を提供する。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | 問い合わせ概要 | 直近の問い合わせ件数やよく聞かれる質問のサマリーを表示 |
| 2 | ドキュメント管理への導線 | ドキュメント管理画面への遷移リンク |
| 3 | FAQ管理への導線 | FAQ管理画面への遷移リンク |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| ヘッダー | アプリ名、管理者名、ログアウトボタン | 上部 |
| サイドナビゲーション | ダッシュボード、ドキュメント管理、FAQ管理へのリンク | 左側 |
| 問い合わせサマリーカード | 直近の質問件数、よく聞かれるトピックTOP5 | メインエリア上部 |
| フィードバックサマリー | 「役に立たなかった」評価が多い質問のリスト | メインエリア中央 |
| クイックアクションボタン | 「PDFアップロード」「FAQ追加」のショートカット | メインエリア上部右 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| 問い合わせ概要 | サマリーカード + フィードバックサマリー | 画面表示時にデータを取得し表示 |
| ドキュメント管理への導線 | サイドナビゲーション + クイックアクションボタン | クリックでドキュメント管理画面へ遷移 |
| FAQ管理への導線 | サイドナビゲーション + クイックアクションボタン | クリックでFAQ管理画面へ遷移 |
