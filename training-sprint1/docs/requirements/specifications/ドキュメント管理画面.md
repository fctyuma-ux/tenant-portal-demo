# 仕様書: ドキュメント管理画面

## 目的

物件管理者がテナントマニュアルPDFをアップロードし、AIのナレッジベースとして登録・管理する画面。アップロード後に公開する前に、テストプレビュー機能で正しくAI回答が生成されるかを確認できる。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | PDFアップロード | マニュアルPDFをドラッグ＆ドロップまたはファイル選択でアップロード |
| 2 | ドキュメント一覧 | 登録済みドキュメントの一覧表示（ファイル名、登録日、ステータス） |
| 3 | AI解析処理 | アップロードされたPDFをAIが解析し、ナレッジベースに取り込む |
| 4 | テストプレビュー | 公開前にテスト質問を入力し、AI回答が正しく生成されるかを確認する |
| 5 | 公開・非公開切替 | ドキュメントの公開ステータスを切り替える |
| 6 | ドキュメント削除 | 不要になったドキュメントを削除する |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| ヘッダー・サイドナビ | 共通ナビゲーション | 上部・左側 |
| アップロードエリア | ドラッグ＆ドロップ対応のファイルアップロードゾーン | メインエリア上部 |
| 解析プログレスバー | PDFの解析進捗を表示（解析中/完了/エラー） | アップロードエリア内 |
| ドキュメント一覧テーブル | ファイル名、登録日、ページ数、ステータス（解析中/未公開/公開中）を表示 | メインエリア中央 |
| 公開トグルスイッチ | 各ドキュメントの公開/非公開を切り替えるスイッチ | 一覧テーブル内 |
| 削除ボタン | 各ドキュメントの削除ボタン（確認ダイアログ付き） | 一覧テーブル内 |
| テストプレビュー枠 | テスト質問の入力欄とAI回答の表示エリア（簡易チャット形式） | メインエリア下部（または右パネル） |
| テスト質問入力 | テスト用の質問を入力するテキストフィールド | テストプレビュー枠内 |
| テスト回答表示 | AI回答と引用画像のプレビュー | テストプレビュー枠内 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| PDFアップロード | アップロードエリア | PDFをドラッグ＆ドロップまたはクリックでファイル選択。アップロード後、解析が自動開始 |
| AI解析処理 | 解析プログレスバー | アップロード後に自動でプログレスバーが進行し、完了時にステータスが「未公開」に変化 |
| ドキュメント一覧 | ドキュメント一覧テーブル | 登録済みドキュメントをテーブル形式で表示。ステータスでフィルタ可能 |
| テストプレビュー | テスト質問入力 + テスト回答表示 | テスト質問を入力→送信で、未公開ドキュメントを含むナレッジベースに対してAI回答を生成・表示 |
| 公開・非公開切替 | 公開トグルスイッチ | トグル操作でステータスを切り替え。公開時に確認ダイアログ表示 |
| ドキュメント削除 | 削除ボタン | クリックで確認ダイアログ表示後、削除実行 |
