# 要件定義書 v2: 製造ダッシュボード＆報告画面（P002）

> DB設計を踏まえた要件定義書の更新

## 目的

製造部門（田中）がトラブル発生時にテキスト入力で報告を起票し、入力中にRAGがリアルタイムで類似事例の解決策をサジェストする。Charge-back成功累計金額の表示で報告モチベーションを維持する。

## 機能

| # | 機能 | 説明 | DB関連テーブル |
|---|------|------|--------------|
| 1 | トラブル報告起票 | 設備名・ライン名・現象テキスト・エラーコード・停止時間を入力し新規トラブルを起票 | `equipment` READ, `lines` READ |
| 2 | RAGリアルタイムサジェスト | 現象テキスト入力中にデバウンス付きで過去の類似トラブル解決策をリアルタイム検索・提示 | FAISS READ → `trouble_reports` JOIN（internal_id）, `ai_analyses` READ |
| 3 | Charge-back累計表示 | 今月の設計部門へのCharge-back成功累計金額を表示 | `chargebacks` READ |
| 4 | 報告送信 | 入力内容を確定しAI解析へ送信、P003へ遷移 | `trouble_reports` INSERT |
| 5 | 過去報告一覧 | 自分が起票した直近のトラブル報告をリスト表示 | `trouble_reports` READ, `ai_analyses` READ, `equipment` READ |

## Input / Process / Output

| 機能 | Input | Process | Output | DB関連テーブル |
|------|-------|---------|--------|--------------|
| トラブル報告起票 | 設備名（選択）、ライン名（選択）、現象テキスト（自由記述）、エラーコード（任意）、停止時間（分、数値） | 入力値のバリデーション（設備名・ライン名・現象テキスト・停止時間は必須）。選択肢はマスタテーブルから取得 | バリデーション通過: 送信可能状態 / バリデーションエラー: エラーメッセージ表示 | `equipment` READ, `lines` READ |
| RAGリアルタイムサジェスト | 現象テキスト（入力中の文字列、デバウンス500ms） | 入力テキストをベクトル化し、FAISSにセマンティック検索（internal_idで検索→`trouble_reports`にJOIN）。類似度上位5件を取得 | 類似トラブルのリスト（現象・解決策・類似度スコア） | FAISS READ → `trouble_reports` JOIN（internal_id）, `ai_analyses` READ |
| Charge-back累計表示 | ログインユーザーID、当月の期間 | `chargebacks`テーブルから当月のレコードをSUM（amount_yen） | 累計金額（¥表示） | `chargebacks` READ |
| 報告送信 | 起票済みのフォームデータ | `trouble_reports`テーブルにINSERT（internal_id自動採番）。AI解析ジョブをキューに投入 | 保存成功: P003（AI解析結果画面）へ遷移 / 保存失敗: エラーメッセージ | `trouble_reports` INSERT |
| 過去報告一覧 | ログインユーザーID | `trouble_reports`テーブルからreported_by=ユーザーIDで日時降順取得（直近20件）。`ai_analyses`と`equipment`をJOIN | トラブル報告リスト（日時・設備名・ステータス・損失額） | `trouble_reports` READ, `ai_analyses` READ, `equipment` READ |

## UI状態遷移

| 要素 | 対応機能 | 状態 | DB関連テーブル |
|------|---------|------|--------------|
| 設備名セレクト | トラブル報告起票 | 未選択 → 選択済み | `equipment` READ |
| ライン名セレクト | トラブル報告起票 | 未選択（設備名選択後に選択肢が絞り込まれる）→ 選択済み | `lines` READ |
| 現象テキストエリア | トラブル報告起票 + RAGサジェスト | 空 → 入力中（→ デバウンス後にRAG検索発火）→ 入力完了 | ― |
| エラーコード入力 | トラブル報告起票 | 空 → 入力中（任意項目） | ― |
| 停止時間入力 | トラブル報告起票 | 空 → 入力中 → バリデーションエラー（非数値） | ― |
| RAGサジェストパネル | RAGリアルタイムサジェスト | 非表示 → ローディング（検索中）→ 結果表示（0〜5件）→ 結果なし表示 | FAISS → `trouble_reports`（internal_id JOIN） |
| 解析実行ボタン | 報告送信 | 無効（必須項目未入力）→ 有効（必須項目入力完了）→ ローディング（送信中）→ 遷移 | `trouble_reports` INSERT |
| Charge-back累計カード | Charge-back累計表示 | ローディング → 金額表示 | `chargebacks` READ |
| 直近報告リスト | 過去報告一覧 | ローディング → リスト表示 → 空リスト表示（報告なし） | `trouble_reports` READ |
