# 要件定義書: トラブル履歴・ナレッジ検索画面（P006）

## 目的

製造・設計の両部門が、過去の全構造化トラブルデータを検索・閲覧し、解決済みナレッジを活用する。検索はハイブリッド方式（セマンティック検索＋キーワード検索）をトグルで切り替え、表記揺れの吸収と正確なファクト抽出を両立する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | セマンティック検索 | 自然言語による意味ベースの検索。表記揺れ（例: アームが動かない / 腕が停止）を吸収し、類似トラブルを網羅的に検索。P002のRAG検索エンジンと共通基盤 | 新規 |
| 2 | キーワード検索 | エラーコード（例: E-401）や部品型番（例: PRT-015）などのピンポイント検索。完全一致・部分一致によるファクト抽出 | 新規 |
| 3 | 検索モード切り替え | 「自然言語検索」と「型番/コード検索」のトグルボタンで切り替え | 新規 |
| 4 | フィルタ絞り込み | 設備名・部品名・期間・ステータス・原因区分（設計/製造）での絞り込み。検索モードに関わらず共通で適用 | 新規 |
| 5 | トラブル履歴一覧表示 | 検索結果を一覧テーブルで表示（ページネーション付き） | 新規 |
| 6 | ソート | 日時・損失額・設備名などでソート切り替え | 新規 |
| 7 | ナレッジ閲覧 | トラブルの詳細情報・解決策・対策内容をモーダルで表示 | 新規 |
| 8 | 対策済みフィルタ | 対策完了済みのナレッジのみを表示するトグル | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| セマンティック検索 | 自然言語テキスト（例: 「溶接ロボットのアームが止まる」） | 入力テキストをベクトル化し、トラブルDBに対してベクトル類似度検索を実行（P002のRAGと共通のEmbeddingモデル・ベクトルDB）。類似度スコア上位を取得 | 類似トラブルのリスト（類似度スコア付き） |
| キーワード検索 | キーワード文字列（例: 「E-401」「PRT-015」） | DBに対してLIKE検索（部分一致）を実行。エラーコード・部品型番・現象テキストなどの各カラムを横断検索 | マッチしたトラブルのリスト |
| 検索モード切り替え | トグルの選択状態（自然言語 / 型番・コード） | 選択されたモードに応じて検索エンジンを切り替え。検索窓のプレースホルダーもモードに応じて変更 | 検索モードの状態変更、プレースホルダー更新 |
| フィルタ絞り込み | 設備名（選択）、部品名（選択）、期間（開始日・終了日）、ステータス（選択）、原因区分（選択） | 検索結果に対してフィルタ条件をANDで追加適用 | フィルタ適用後の結果リスト |
| トラブル履歴一覧表示 | 検索結果データ、ページ番号 | 1ページあたり20件で表示。ページネーション計算 | テーブル表示（日時・設備名・現象・損失額・ステータス・原因区分） |
| ソート | ソートキー（日時/損失額/設備名）、ソート順（昇順/降順） | 検索結果をソートキーで並べ替え | ソート済みリストの再表示 |
| ナレッジ閲覧 | トラブルレポートID（行クリック） | 該当レポートの全詳細（AI構造化データ・解決策・対策内容・対策ステータス）を取得 | モーダルに詳細情報を表示 |
| 対策済みフィルタ | トグルのON/OFF | ONの場合、ステータスが「完了（Fixed）」のレコードのみに絞り込み | フィルタ適用後の結果リスト |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| 検索モードトグル | 検索モード切り替え | 「自然言語検索」（デフォルト）↔「型番/コード検索」 |
| 検索窓 | セマンティック検索 / キーワード検索 | 空（プレースホルダー: モード別に変化）→ 入力中 → Enter/検索ボタンで検索実行 |
| 検索窓プレースホルダー | 検索モード切り替え | 自然言語モード: 「トラブルの状況を入力...」/ 型番・コードモード: 「エラーコードや部品型番を入力...」 |
| フィルタパネル | フィルタ絞り込み | 折りたたみ（デフォルト）→ 展開 → フィルタ選択中 → 適用済み（バッジ表示） |
| トラブル履歴テーブル | トラブル履歴一覧表示 | 初期表示（全件）→ ローディング（検索中）→ 結果表示 → 結果なし表示 |
| カラムヘッダー | ソート | 未ソート → 昇順（▲）→ 降順（▼）→ 未ソート（クリックで循環） |
| ステータスバッジ | トラブル履歴一覧表示 | 未対応（赤）/ 対応中（黄）/ 完了（緑） |
| 対策済みフィルタトグル | 対策済みフィルタ | OFF（全件表示）↔ ON（完了のみ表示） |
| ナレッジ詳細モーダル | ナレッジ閲覧 | 非表示 → 表示（行クリック）→ 非表示（閉じるボタン） |
