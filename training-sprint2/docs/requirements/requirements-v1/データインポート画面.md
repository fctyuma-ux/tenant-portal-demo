# 要件定義書: データインポート画面 - バックオフィス（P007）

## 目的

管理者が過去に蓄積されたトラブルデータ（固定フォーマットCSV）を一括でDBに取り込み、AIによる構造化処理をバッチ実行する。LLMの処理時間（1件あたり数秒）を考慮し、FastAPI BackgroundTasksによる簡易非同期処理＋フロントエンドからのポーリングで進捗を表示する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | CSVファイルアップロード | 固定フォーマットの過去トラブルデータCSVをアップロード。カラムマッピングは不要 | 新規 |
| 2 | データプレビュー | アップロードCSVの先頭数行をプレビュー表示し、フォーマット適合を確認 | 新規 |
| 3 | AI構造化バッチ実行 | 全レコードに対してLLMで構造化処理（現象/原因分類・損失額計算）をバッチ実行。FastAPI BackgroundTasksで非同期処理 | 新規 |
| 4 | 処理進捗ポーリング | フロントエンドから数秒ごとに進捗APIをポーリングし、プログレスバーを更新 | 新規 |
| 5 | インポート結果確認 | 処理完了後の結果サマリー（成功件数・エラー件数・エラー詳細） | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| CSVファイルアップロード | CSVファイル（固定フォーマット: record_id, 発生日時, 完了日時, 工場, ラインID, ライン名, 設備ID, 設備名, 設備メーカー, 導入年, 製品カテゴリ, 対象製品, 型番, トラブル区分, 停止時間_分, 生産影響, 担当者コード, 部品コード, 交換部品名, 部品費_円, 外注費_円, 合計コスト_円, 現象記述, 原因記述, 処置記述, 備考_引継ぎ） | ファイルサイズ・拡張子のバリデーション。CSVパースしヘッダー行の26カラム名を固定フォーマットと照合 | フォーマット適合: プレビュー表示 / 不適合: エラーメッセージ（不足カラム名を明示） |
| データプレビュー | パース済みCSVデータ | 先頭10行を表示用に整形。総行数（インポート対象件数）を算出 | プレビューテーブル（先頭10行）、総件数表示 |
| AI構造化バッチ実行 | インポート対象の全レコード（26カラム） | (1) CSVの各行をパースし、マスタデータ（工場・ライン・設備・部品）をupsert、トランザクションデータ（トラブルレポート）をINSERT（ステータス: pending）。(2) FastAPI BackgroundTasksでジョブ起動。(3) 1件ずつ現象記述・原因記述・処置記述をLLMに送信し、構造化データ（現象カテゴリ・推定根本原因・設計起因度）を取得。(4) 構造化結果＋元テキストをベクトル化しベクトルDBに登録。(5) 各レコードのステータスをpending→processing→completed/errorに更新 | ジョブID（進捗ポーリング用） |
| 処理進捗ポーリング | ジョブID | フロントエンドが3秒間隔で進捗APIを呼び出し。APIは処理済み件数/総件数/エラー件数を返す | 進捗率（%）、処理済み件数、エラー件数、完了フラグ |
| インポート結果確認 | ジョブID（完了後） | ジョブの最終結果を集計。エラーレコードがあれば原因（LLMタイムアウト・パースエラー等）を取得 | 結果サマリー（成功件数・エラー件数）、エラー詳細リスト（行番号・エラー内容） |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| CSVアップロードエリア | CSVファイルアップロード | 待機（ドラッグ&ドロップ可）→ ファイル選択済み（ファイル名表示）→ バリデーション中 → 成功（プレビュー表示）/ エラー（フォーマット不適合メッセージ） |
| データプレビューテーブル | データプレビュー | 非表示 → 表示（先頭10行＋総件数） |
| インポート実行ボタン | AI構造化バッチ実行 | 非表示（未アップロード）→ 有効（プレビュー表示後）→ 無効（処理中）→ 非表示（完了後） |
| プログレスバー | 処理進捗ポーリング | 非表示 → 表示（0%）→ 進行中（n%、3秒ごとに更新）→ 完了（100%） |
| 処理件数カウンター | 処理進捗ポーリング | 非表示 → 「処理中: X / Y 件（エラー: Z 件）」 |
| 処理結果サマリー | インポート結果確認 | 非表示 → 表示（成功件数・エラー件数） |
| エラー詳細リスト | インポート結果確認 | 非表示 → 表示（エラーがある場合のみ。行番号＋エラー内容のリスト） |
