# 要件定義書: 設計ダッシュボード - 全社品質コストMonitor（P004）

## 目的

設計部門（佐藤）が自部門に請求された設計起因の損失総額を把握し、本格的なパレート図（棒グラフ＋累積線）でワースト設備・ワースト部品ランキングを可視化して、修正の優先順位を判断する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | 設計起因損失総額表示 | 今月・累計の設計部門に請求された損失総額を表示 | 新規 |
| 2 | ワーストランキング表示 | 金額ベースでワースト設備・ワースト部品を本格パレート図（棒グラフ＋累積線）で表示 | 新規 |
| 3 | 期間フィルタ | 表示期間（今月/四半期/年間/全期間）の切り替え | 新規 |
| 4 | トラブル詳細への遷移 | ランキング項目をクリックしてP005（トラブル詳細・対策実行画面）へ遷移 | 新規 |
| 5 | 新着請求通知 | ページ読み込み時に未読のCharge-back請求をリスト表示 | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| 設計起因損失総額表示 | 期間フィルタの選択値、ログインユーザーの部門 | 選択期間内のCharge-backレコードを集計（SUM）。前期比も算出 | 損失総額（¥表示）、前期比（増減率） |
| ワーストランキング表示 | 期間フィルタの選択値 | 設備別・部品別にCharge-back金額を集計し、金額降順でソート。累積比率を計算 | パレート図データ（設備名/部品名、金額、累積比率） |
| 期間フィルタ | ユーザーの期間選択（今月/四半期/年間/全期間） | 選択期間でクエリを再実行 | 損失総額・パレート図の再計算・再描画 |
| トラブル詳細への遷移 | クリックされた設備ID/部品ID | 遷移先URLにIDをパラメータとして付与 | P005への画面遷移 |
| 新着請求通知 | ログインユーザーの部門、未読フラグ | ページ読み込み時に未読のCharge-backレコードを取得 | 未読請求リスト（件数バッジ＋リスト表示） |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| 損失総額サマリーカード | 設計起因損失総額表示 | ローディング → 金額表示（前期比付き） |
| 期間フィルタタブ | 期間フィルタ | 今月（デフォルト選択）/ 四半期 / 年間 / 全期間 → 切り替え時にローディング → 再描画 |
| ワースト設備パレート図 | ワーストランキング表示 | ローディング → チャート表示 → データなし表示 |
| ワースト部品パレート図 | ワーストランキング表示 | ローディング → チャート表示 → データなし表示 |
| ランキング項目 | トラブル詳細への遷移 | 通常 → ホバー（ハイライト）→ クリック（P005へ遷移） |
| 新着請求バッジ | 新着請求通知 | ローディング → 件数表示（未読あり）→ 非表示（未読なし） |
| 新着請求リスト | 新着請求通知 | 折りたたみ → 展開（バッジクリック）→ 項目クリックでP005へ遷移 |
