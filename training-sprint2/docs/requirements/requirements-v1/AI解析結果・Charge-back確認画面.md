# 要件定義書: AI解析結果・Charge-back確認画面（P003）

## 目的

AIが構造化したトラブルデータ（現象/原因の分類）と自動計算された総損失額（修繕費＋機会損失）をプレビューし、設計部門への責任コスト請求（Charge-back）を即時実行する。

## 機能

| # | 機能 | 説明 | v1からの変更点 |
|---|------|------|--------------|
| 1 | AI構造化データ表示 | AIが入力テキストから抽出した「現象」「推定原因」「関連部品」「過去類似件数」を表示 | 新規 |
| 2 | 総損失額プレビュー | 直接費（修繕費・部品代）＋機会損失（停止時間×ライン別単価）の内訳と合計を表示 | 新規 |
| 3 | 責任判定表示 | AIが判定した設計起因度（%）と判定根拠を表示 | 新規 |
| 4 | Charge-back実行 | 設計部門への責任コスト請求を即時実行（承認フローなし） | 新規 |
| 5 | 報告の修正 | AI構造化データの内容を手動で修正・補足 | 新規 |

## Input / Process / Output

| 機能 | Input | Process | Output |
|------|-------|---------|--------|
| AI構造化データ表示 | トラブルレポートID（P002から遷移時に取得） | AI解析ジョブの結果をDBから取得。現象テキストをNLPで分類し、部品マスタとの照合、過去トラブルDBとの類似度検索を実行 | 構造化データ（現象カテゴリ、推定原因、関連部品名、過去類似件数） |
| 総損失額プレビュー | 停止時間（分）、ライン名 | ラインマスタからライン別単価（¥/分）を取得。直接費はユーザー入力またはデフォルト値。機会損失 = 停止時間 × ライン別単価 | 損失額内訳（直接費 + 機会損失 = 総損失額） |
| 責任判定表示 | トラブルレポートID、AI解析結果 | 過去の類似トラブルの発生パターン・頻度・構造的要因をAIが分析し、設計起因度（0〜100%）を算出 | 設計起因度（%）、判定根拠テキスト |
| Charge-back実行 | トラブルレポートID、総損失額、設計起因度 | Charge-backレコードをDBに作成（金額 = 総損失額 × 設計起因度/100）。設計部門のダッシュボードに即時反映 | 成功: P002へ遷移（累計金額更新）/ 失敗: エラーメッセージ |
| 報告の修正 | 修正後の構造化データ（現象・原因・部品の変更） | 修正内容でAI解析結果を上書き更新。損失額・責任判定を再計算 | 更新された構造化データ・損失額・責任判定の再表示 |

## UI状態遷移

| 要素 | 対応機能 | 状態 |
|------|---------|------|
| AI構造化データカード | AI構造化データ表示 | ローディング（AI解析中）→ 結果表示 → 編集モード（修正ボタン押下時） |
| 損失額内訳パネル | 総損失額プレビュー | ローディング → 金額表示（直接費・機会損失・総額の内訳） |
| 責任判定パネル | 責任判定表示 | ローディング → 判定結果表示（起因度%＋根拠テキスト） |
| 修正ボタン | 報告の修正 | 表示モード: 「修正」→ 編集モード: 「保存」「キャンセル」 |
| 設計へ請求ボタン | Charge-back実行 | 無効（AI解析中）→ 有効（解析完了）→ ローディング（請求処理中）→ 完了（P002へ遷移） |
