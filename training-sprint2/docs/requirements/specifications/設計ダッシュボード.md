# 仕様書: 設計ダッシュボード（全社品質コストMonitor）

## ページID
P004

## 目的

設計部門（佐藤）が、自部門に請求された設計起因の損失総額を把握し、金額ベースのパレート分析（ワースト設備・ワースト部品ランキング）で修正の優先順位を判断する。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | 設計起因損失総額表示 | 今月・累計の設計部門に請求された損失総額を表示 |
| 2 | ワーストランキング表示 | 金額ベースでワースト設備・ワースト部品をパレート図で表示 |
| 3 | 期間フィルタ | 表示期間（今月/四半期/年間/全期間）の切り替え |
| 4 | トラブル詳細への遷移 | ランキング項目をクリックして詳細・対策画面へ遷移 |
| 5 | 新着請求通知 | 製造部門から新たにCharge-backされた未読請求の通知 |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| 損失総額サマリーカード | 今月の設計起因損失総額を大きく表示 | 上部 |
| 期間フィルタ | 今月/四半期/年間/全期間の切り替えタブ | サマリーカード下 |
| ワースト設備ランキング | 損失額が大きい設備のパレート図（棒グラフ＋累積線） | 中央左 |
| ワースト部品ランキング | 損失額が大きい部品のパレート図（棒グラフ＋累積線） | 中央右 |
| 新着請求リスト | 未読のCharge-back請求をリスト表示 | 上部右またはサイドバー |
| ランキング項目 | クリックでトラブル詳細・対策画面（P005）へ遷移 | ランキング内 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| 設計起因損失総額表示 | 損失総額サマリーカード | ページ読み込み時に選択期間の損失総額を取得・表示 |
| ワーストランキング表示 | ワースト設備ランキング + ワースト部品ランキング | パレート図で金額順にランキング表示。累積比率線で上位集中度を可視化 |
| 期間フィルタ | 期間フィルタ | タブ切り替えでサマリー・ランキングが再計算・再描画 |
| トラブル詳細への遷移 | ランキング項目 | ランキングの設備名・部品名をクリックしてP005へ遷移 |
| 新着請求通知 | 新着請求リスト | 未読件数のバッジ表示。リスト項目クリックでP005へ遷移 |
