# 仕様書: データインポート画面（バックオフィス）

## ページID
P007

## 目的

管理者が過去に蓄積されたトラブルデータ（CSV）を一括でDBに取り込み、AIによる構造化処理をバッチ実行する。システム導入初期のデータ移行や、既存システムからの定期データ連携に使用する。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | CSVファイルアップロード | 固定フォーマット（26カラム: record_id, 発生日時, 完了日時, 工場, ラインID, ライン名, 設備ID, 設備名, 設備メーカー, 導入年, 製品カテゴリ, 対象製品, 型番, トラブル区分, 停止時間_分, 生産影響, 担当者コード, 部品コード, 交換部品名, 部品費_円, 外注費_円, 合計コスト_円, 現象記述, 原因記述, 処置記述, 備考_引継ぎ）の過去トラブルデータCSVをアップロード |
| 2 | データプレビュー | アップロードCSVの先頭10行をプレビュー表示し、26カラムのフォーマット適合を確認 |
| 3 | AI構造化バッチ実行 | マスタデータ（工場・ライン・設備・部品）をupsertし、現象記述・原因記述・処置記述をLLMで構造化（現象カテゴリ・推定根本原因・設計起因度）。結果をベクトルDBにも登録。FastAPI BackgroundTasksで非同期実行 |
| 4 | 処理進捗表示 | バッチ処理の進捗状況（処理中/完了/エラー件数）をリアルタイム表示 |
| 5 | インポート結果確認 | インポート完了後の処理結果サマリー（成功件数・エラー件数・エラー詳細） |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| CSVアップロードエリア | ドラッグ&ドロップまたはファイル選択でCSVをアップロード | 上部 |
| データプレビューテーブル | アップロードしたCSVの先頭数行をプレビュー表示 | 中央 |
| フォーマット適合表示 | 26カラムの検出結果（OK/不足カラム名）を表示 | プレビューテーブル上 |
| インポート実行ボタン | AI構造化処理を含むインポートを開始するボタン | プレビュー下 |
| 進捗バー | バッチ処理の進捗率を表示するプログレスバー | インポート実行ボタン下 |
| 処理結果サマリー | 成功件数・エラー件数・エラー詳細 | 進捗バー下 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| CSVファイルアップロード | CSVアップロードエリア | ドラッグ&ドロップまたはファイル選択でCSVを読み込み |
| データプレビュー | データプレビューテーブル + フォーマット適合表示 | アップロード完了後、自動的にプレビュー表示と26カラムの適合チェック結果を表示 |
| AI構造化バッチ実行 | インポート実行ボタン | ボタン押下でバッチ処理を開始 |
| 処理進捗表示 | 進捗バー | バッチ処理中にリアルタイムで進捗率を更新 |
| インポート結果確認 | 処理結果サマリー | バッチ完了後に成功・エラーの件数と詳細を表示 |
