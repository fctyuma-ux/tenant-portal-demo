# 仕様書: トラブル詳細・対策実行画面（統合画面）

## ページID
P005

## 目的

特定の設備・部品に関するトラブルの詳細なAI分析理由を確認し、ROIシミュレーションで対策の投資対効果を試算した上で、対策ステータスを更新する。ステータス更新時に現場（田中）へ自動通知を送信する。佐藤のPhase 2（分析）とPhase 3（対策実行）を1画面に統合。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | AI分析詳細表示 | 該当設備・部品に関する過去全トラブルのAI分析結果を集約表示 |
| 2 | トラブル履歴一覧 | この設備・部品に関する過去のトラブル発生履歴（日時・損失額・原因）をリスト表示 |
| 3 | ROIシミュレーション（数値算出） | 過去実績の年換算で予測損失額を堅実に計算（システムロジック）。対策コスト vs 予測損失額を比較し回収期間（Payback Period）を算出。財務的根拠（Accountability）の正確性を担保 |
| 4 | AI投資提案文の自動生成 | ROI数値＋RAGの類似トラブルテキスト群をLLMに渡し、「なぜこの設計変更が必要か（技術的背景）」「放置した場合の経営的リスク（財務的解釈）」「推奨アクション」を含む投資実行の提案文（示唆）を自動生成 |
| 5 | 対策ステータス更新 | 未対応 / 対応中 / 完了（Fixed）のステータスを変更 |
| 6 | 現場自動通知 | ステータスを「完了」に変更した際、関連するトラブル報告者（田中）へ自動通知を送信 |
| 7 | ROI分析レポート出力 | 上司への決裁用資料としてROI数値＋AI提案文を画面印刷（CSS制御）で出力 |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| 設備・部品ヘッダー | 対象設備名・部品名・累積損失額のサマリー | 上部 |
| AI分析サマリーカード | AIが分析した主要な原因パターン・頻出キーワード | 上部下 |
| トラブル履歴テーブル | 過去のトラブル発生日時・現象・損失額・対応内容の一覧 | 中央 |
| ROIシミュレーションパネル | 対策コスト入力 + 予測損失額 + 回収期間の数値表示（システムロジック） | 中央下または右サイド |
| 対策コスト入力フィールド | 恒久対策にかかる見積りコストを入力 | ROIパネル内 |
| AI提案文パネル | LLMが生成した投資実行の提案文（技術的背景・経営的リスク・推奨アクション） | ROIパネル下 |
| 提案文生成ボタン | ROI数値確定後、AI提案文の生成をトリガーするボタン | ROIパネル内 |
| 対策ステータスセレクト | 未対応 / 対応中 / 完了 のドロップダウンまたはボタングループ | 下部 |
| レポート出力ボタン | ROI数値＋AI提案文を画面印刷で出力するボタン | AI提案文パネル内 |
| 戻るボタン | 設計ダッシュボード（P004）へ戻る | 上部左 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| AI分析詳細表示 | AI分析サマリーカード | ページ読み込み時に該当設備・部品の全トラブルデータからAI分析結果を取得・表示 |
| トラブル履歴一覧 | トラブル履歴テーブル | 時系列でトラブル履歴を表示。行クリックで個別トラブルの詳細をモーダル表示 |
| ROIシミュレーション（数値算出） | ROIシミュレーションパネル + 対策コスト入力フィールド | 対策コストを入力すると、システムロジックで予測損失額・回収期間を自動計算（Deterministic） |
| AI投資提案文の自動生成 | 提案文生成ボタン → AI提案文パネル | ROI数値確定後、ボタン押下でLLMにROI数値＋RAGテキスト群を渡し、提案文を生成・表示 |
| 対策ステータス更新 | 対策ステータスセレクト | ステータス変更時に確認ダイアログを表示し、更新を実行 |
| 現場自動通知 | 対策ステータスセレクト | ステータスを「完了」に変更した時点で、関連トラブル報告者へ自動通知をトリガー |
| ROI分析レポート出力 | レポート出力ボタン | ボタン押下でROI数値＋AI提案文を含む画面を印刷用レイアウトで出力（@media print） |
