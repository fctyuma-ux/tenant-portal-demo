# 仕様書: トラブル履歴・ナレッジ検索画面

## ページID
P006

## 目的

製造・設計の両部門が、過去の全構造化トラブルデータを検索・閲覧し、解決済みナレッジを活用する。組織全体のナレッジベースとして機能する共通画面。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | トラブル履歴一覧表示 | 過去の全トラブル報告をリスト表示（日時・設備・部品・損失額・ステータス） |
| 2 | 高度な検索 | キーワード・設備名・部品名・期間・ステータス・原因区分（設計/製造）で絞り込み検索 |
| 3 | ナレッジ閲覧 | 解決済みトラブルの対策内容・解決策をナレッジとして閲覧 |
| 4 | ソート | 日時・損失額・設備名などでソート切り替え |
| 5 | 対策済みフィルタ | 対策完了済みのナレッジのみを表示するフィルタ |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| 検索バー | キーワードによるフリーテキスト検索 | 上部 |
| フィルタパネル | 設備・部品・期間・ステータス・原因区分のフィルタ | 検索バー下またはサイドバー |
| トラブル履歴テーブル | 全トラブル報告の一覧テーブル（ページネーション付き） | 中央メイン |
| ステータスバッジ | 未対応/対応中/完了をカラーバッジで表示 | テーブル内 |
| 対策済みフィルタトグル | 対策完了済みのナレッジのみ表示する切り替え | フィルタパネル内 |
| ナレッジ詳細モーダル | トラブルの詳細情報・解決策・対策内容を表示 | モーダル |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| トラブル履歴一覧表示 | トラブル履歴テーブル | ページ読み込み時に全トラブル履歴を取得し、テーブルに表示 |
| 高度な検索 | 検索バー + フィルタパネル | キーワード入力やフィルタ選択でテーブルの表示内容をリアルタイムに絞り込み |
| ナレッジ閲覧 | トラブル履歴テーブル → ナレッジ詳細モーダル | テーブルの行クリックで詳細モーダルを表示。解決策・対策内容を確認 |
| ソート | トラブル履歴テーブルのカラムヘッダー | カラムヘッダークリックで昇順/降順ソート切り替え |
| 対策済みフィルタ | 対策済みフィルタトグル | トグルONで対策完了済みのレコードのみ表示 |
