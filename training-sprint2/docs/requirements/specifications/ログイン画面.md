# 仕様書: ログイン画面

## ページID
P001

## 目的

メールアドレスとパスワードによるユーザー認証を行い、Role（製造部門 / 設計部門）に応じて適切なダッシュボードへ振り分ける。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | メール・パスワード認証 | Supabase Authを使ったメールアドレス＋パスワードによるログイン |
| 2 | Role判定 | ログインしたユーザーのメールアドレスまたはプロファイルからRole（製造/設計/管理者）を判定 |
| 3 | Role別リダイレクト | 製造部門 → 製造ダッシュボード（P002）、設計部門 → 設計ダッシュボード（P004）へ自動遷移 |
| 4 | エラー表示 | 認証失敗時のエラーメッセージ表示 |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| アプリロゴ・タイトル | アプリ名の表示 | 上部中央 |
| メールアドレス入力フィールド | ログイン用メールアドレス | 中央 |
| パスワード入力フィールド | ログイン用パスワード | メール入力の下 |
| ログインボタン | 認証を実行する | パスワード入力の下 |
| エラーメッセージ表示エリア | 認証失敗時のメッセージ | ログインボタンの下 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| メール・パスワード認証 | メール入力 + パスワード入力 + ログインボタン | ログインボタン押下でSupabase Authに認証リクエスト |
| Role判定 | - | 認証成功後、サーバー側でRoleを取得 |
| Role別リダイレクト | - | Role判定結果に応じて自動的に対応するダッシュボードへ遷移 |
| エラー表示 | エラーメッセージ表示エリア | 認証失敗時にエラー内容を表示 |
