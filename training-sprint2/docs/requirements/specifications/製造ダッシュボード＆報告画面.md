# 仕様書: 製造ダッシュボード＆報告画面

## ページID
P002

## 目的

製造部門（田中）が、トラブル発生時にテキスト入力で報告を起票し、入力中にRAGが類似事例の解決策をリアルタイムにサジェストする。また、今月の設計部門へのCharge-back成功累計金額を表示し、報告のモチベーションを維持する。

## 機能一覧

| # | 機能 | 説明 |
|---|------|------|
| 1 | トラブル報告起票 | テキスト入力で現象・エラーコード・停止時間などを入力し、新規トラブルを起票する |
| 2 | RAGリアルタイムサジェスト | 入力中の自然言語テキストから、過去の類似トラブルの解決策をリアルタイムに検索・提示する |
| 3 | Charge-back累計表示 | 今月、設計部門へチャージバック（コスト移転）に成功した累計金額を表示する |
| 4 | 報告送信 | 入力内容を確定し、AI解析へ送信する |
| 5 | 過去報告一覧 | 自分が起票した直近のトラブル報告をリスト表示する |

## UI要素

| 要素 | 説明 | 位置 |
|------|------|------|
| Charge-back累計カード | 「今月のCharge-back成功額: ¥X,XXX,XXX」を表示するサマリーカード | 上部 |
| トラブル報告フォーム | テキスト入力エリア（現象・エラーコード・停止時間等） | 中央メイン |
| 現象テキスト入力 | トラブルの現象を自然言語で記述するテキストエリア | フォーム内上部 |
| エラーコード入力 | 設備のエラーコードを入力するフィールド | フォーム内 |
| 停止時間入力 | ライン停止時間（分）を入力する数値フィールド | フォーム内 |
| RAGサジェストパネル | 入力内容に基づく類似事例・解決策のリアルタイム表示エリア | フォーム右側またはフォーム下部 |
| 解析実行ボタン | 入力内容を確定しAI解析へ送信するボタン | フォーム下部 |
| 直近報告リスト | 自分が起票した直近のトラブル報告のリスト | 下部 |

## 機能とUIの結びつき

| 機能 | UI要素 | インタラクション |
|------|--------|----------------|
| トラブル報告起票 | 現象テキスト入力 + エラーコード入力 + 停止時間入力 | 各フィールドにトラブル情報を入力 |
| RAGリアルタイムサジェスト | 現象テキスト入力 → RAGサジェストパネル | テキスト入力のたびに（デバウンス付き）RAGが類似事例を検索し、サジェストパネルに解決策を表示 |
| Charge-back累計表示 | Charge-back累計カード | ページ読み込み時に今月の累計を取得・表示 |
| 報告送信 | 解析実行ボタン | ボタン押下で入力データをAI解析に送信し、P003（AI解析結果画面）へ遷移 |
| 過去報告一覧 | 直近報告リスト | リスト項目クリックで該当報告のAI解析結果画面（P003）へ遷移 |
